# 99Ways — EmDash Redesign Project

## Project purpose

Migrate the WordPress `99Ways` site into an EmDash CMS + Astro site and establish the
design foundation for a Phase 2 redesign. WordPress source is **read-only**; all edits
happen in this repo.

## Environment notes

- Dev server: `npm run dev` → `http://localhost:4321` (dev mode; setup requires the
  dev-bypass for first load). Production build: `npm run build`.
- Node modules are symlinked from the sibling checkout `~/projects/emdash-test/node_modules`
  — run `npm install`/upgrades there.
- Disk is tight (~100% of a 38G root device). Avoid leaving large artifacts; the running
  dev server writes to `data.db` and `uploads/`. Do not delete other users' files in `/tmp`.
- The site title `99Ways` and tagline are set in EmDash site settings, not in the repo.

## Design foundation (Phase 1.3)

- Palette (99Ways brand): Graphite `#292B2A`, Warm White `#F4F3EF`, Inquiry Blue `#3558B8`,
  Muted `#676B65`, Green `#147D40`. Grounded in `src/styles/tokens.css`, overridden in
  `src/styles/theme.css`.
- Fonts: Inter (UI) + IBM Plex Mono (accent/code). Configured in `astro.config.mjs`.
- Logo: `src/components/Logo.astro` renders the official `99Ways` SVG wordmark inline
  (color via CSS variables). Asset originals under `logo/wordmark/`.
- Favicon: 99Ways favicon in `public/` (`.svg`, `.png`, `.ico`).
- Homepage `src/pages/index.astro` is an interim post list; the real redesign is Phase 2.

## Migration state

Migrated and verified: 73 posts, 14 pages, 5 categories, 3 bylines, primary nav menu,
76 local featured images, original publish dates, and Yoast SEO metadata.

- Reference docs: `migration/discovery.md`, `mapping.md`, `verification.md`
- Source snapshots: `migration/wordpress-source/*.json` (read-only)
- Seed: `seed/seed.json` — regenerated by `migration/migrate.py`, applied by the EmDash
  seeding flow (`npm run seed`, or admin setup on first boot).

## Working agreements

- WordPress stays read-only. EmDash is the migration target.
- API calls use `Authorization: Bearer ec_pat_*` against `http://localhost:4321` with
  `X-EmDash-Request: 1`, unless using MCP tools.
- Before Phase 2 design work, confirm scope and stop for review; Phase 1 was required to be
  left complete before starting it.

## Commands

- `npm run dev` — run dev server (localhost:4321)
- `npm run build` — production build
- `python3 migration/backdate.py` — restore original publish dates (items already live)
- `python3 migration/apply-seo.py` — apply Yoast SEO to all items
- `git status` / `git log` — review before committing; commit only when asked
