# 99Ways brand assets v1.0

Use the full light-background wordmark by default on Warm White or another verified light, quiet field. Use the dark-background wordmark on Graphite or another verified dark field. The compact 99 is for square profiles, browser icons, and recognized contexts where the full name cannot fit.

- **Standard color:** neutral bodies/lettering plus blue pupils. Choose the light or dark treatment by the local background.
- **One color:** use pure black or pure white when color production is unavailable. The downward pupil structure remains part of the silhouette.
- **Minimum size:** full wordmark 180 CSS px visible width; canonical compact mark 64 CSS px. At 16/24/32/48 px, use the dedicated `icons/micro` file named for that exact target size.
- **Clear space:** at least 25 design units around the visible artwork - one quarter of the 100-unit cap height. Square platform canvases include their own documented padding.
- **Masters:** `masters/wordmark` and `masters/compact` contain editable canonical SVGs with separate pupils and outlined lettering.
- **Delivery files:** `logo` contains flattened SVG/PDF variants; `raster` contains transparent PNGs.
- **Icons:** micro files are size-specific optical derivatives. Do not substitute them for the canonical master at larger sizes. The favicon and Apple touch icon include intentional neutral tiles.

Do not retype the lettering, alter spacing, move pupils independently, recolor the logo with green, stretch it, add a single-9 or 9W form, or place it on a busy/low-contrast field without a neutral holding area.

See [MANIFEST.md](MANIFEST.md), [logo specification](reference/logo-specification.md), and [validation](validation/export-checks.md).
